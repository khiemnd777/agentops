# Policy: MVP Boundaries

This repository implements AgentOps Workspace MVP.

## Allowed

- Asset management.
- Repo scanning and safe materialization.
- File-based run report import.
- Validation and workflow audit.
- Animated playback review.
- Future runner interfaces/stubs.

## Not Allowed In MVP

- Direct Codex, Claude Code, Gemini CLI, or shell-agent execution.
- Live agent streaming.
- Raw log or full diff ingestion/display.
- Complex RBAC.
- Destructive asset/version deletion.
