# Workflow: Repo Change Workflow

Use this for substantial changes to AgentOps Workspace.

1. Classify scope: backend, frontend, database, sync/import/audit, playback, devops, or docs.
2. Read the relevant `.codex/skills/*/SKILL.md` file.
3. Inspect existing code before editing.
4. Make scoped changes that preserve architecture boundaries.
5. Update tests, fixtures, or docs when behavior changes.
6. Run targeted verification.
7. Run broader verification when cross-stack behavior changes.
8. Summarize changed files, verification, and remaining risks.
